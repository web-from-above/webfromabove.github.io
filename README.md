# WEB FROM ABOVE
Hello PFA Users and welcome to Web From Above for Websites!

Credits to [Brian Pantano](https://github.com/brian-pantano) because he made Piano From Abovw


In this Website, you can do more then the original has:

 - [X] Has custom MIDI and SF Parsing
 - [X] Can change Background Brightness
 - [X] Can change the Note Sustain Length (i would reccommend you keeping it to toggled)
 - [X] Can toggle Grid Lines
 - [X] Can Reset your configurations
 - [X] Can Export and Import
 - [X] Can change Note Speed
 - [X] Can change Master Volume
 - [X] Has Audio Limiter (NOT WORKING YET (or does it?))
 - [ ] Performance Improvements (not quite)

> [!WARNING]
> Some things may not work as intended, so if any issues occur, tell us the issue and we'll fix it.

> [!CAUTION]
